# ADR 001: использовать только согласованные публичные источники цен

**Статус:** принято

## Контекст

StockWatch должен получать цены товаров по URL. У ряда магазинов отсутствуют
публично документированные API для каталога, наличия и цен. Использование
внутренних мобильных endpoint'ов или обход ограничений сайтов ненадёжно и может
нарушать правила поставщика.

## Решение

В базовой поставке применяется `UnsupportedPriceSource`, который явно сообщает
об отсутствии подключённого источника. Новый источник реализует протокол
`PriceSource` и добавляется только после отдельной проверки его публичного
контракта и условий использования.

## Последствия

- MVP безопасно демонстрирует очереди, историю цен и уведомления без скрытого
  скрейпинга.
- До подключения разрешённого источника реальные проверки не выполняются.
- Новый адаптер должен иметь отдельные тесты, ограничение частоты запросов и
  документированную конфигурацию.
