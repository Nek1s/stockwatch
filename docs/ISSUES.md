**Labels:** `feature`, `good first issue`  
**Описание:** Создать фабрику FastAPI-приложения, настройки через Pydantic Settings, `/health` и базовую структуру модулей.  
**Критерии готовности:** `/health` возвращает `200`; конфигурация читается из `.env`; маршруты видны в OpenAPI; есть тест endpoint.
